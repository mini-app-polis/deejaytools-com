# Architecture Decision Records — deejaytools-com

This directory contains Architecture Decision Records (ADRs) for the
React web application. ADRs document significant architectural
decisions, the context around them, and their consequences.

## Format

Each ADR is a markdown file named `ADR-NNNN-title-in-kebab-case.md`
where `NNNN` is a zero-padded 4-digit sequence number starting at `0001`.
This matches ecosystem-standards DOC-005. An ADR in another repository is
cited with that repository's name first, as in `api-deejaytools ADR-0006`.
